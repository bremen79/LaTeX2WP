# LaTeX2WP

LaTeX2WP converts mathematical posts written in LaTeX into HTML for WordPress. Write and typeset your post using familiar LaTeX tools, then convert it for publication while keeping the original source for future use.

This is version 0.7.0, a maintained fork of Luca Trevisan’s original LaTeX2WP, based on version 0.6.2. I began extending the program in 2018. The original project also includes contributions from Radu Grigore.

The converter supports common mathematical expressions, theorem-like environments, clickable references, simple document macros, local \input files, and BibTeX citations. Only referenced equations receive numbers. An optional preview uses images generated by WordPress’s LaTeX renderer.

LaTeX2WP supports a subset of LaTeX; it is not a complete TeX interpreter.

## Usage

Requires Python 3. For bibliography support, install:

python -m pip install "bibtexparser>=1.4,<2"

Convert a post:

python latex2wp.py post.tex

This creates post.html, ready to paste into WordPress’s HTML editor. The output uses WordPress’s $latex …$ math syntax.

To also generate a preview:

python latex2wp.py post.tex --preview

Preview generation requires internet access; the resulting post_preview.html embeds the formula images for offline viewing, using the WordPress renderer.

Bibliography paths come from \bibliography{...} in the source. Formatting options and fixed macro replacements are configured in latex2wpstyle.py.
